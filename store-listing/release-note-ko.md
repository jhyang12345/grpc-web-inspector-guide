# 한국어 릴리스 노트

이번 업데이트에서는 gRPC-Web 및 Connect-Web 요청을 보는 데서 더 나아가, 캡처한 unary 요청의 JSON을 직접 편집하고 원래 페이지 프레임을 통해 다시 전송할 수 있도록 했습니다. 재전송된 호출은 Edited 배지와 원본 요청 정보로 명확히 구분되며, 프레임·백엔드 URL, 시작·완료 시각, 소요 시간, 첫 메시지까지 걸린 시간(TTFM), 메시지 수 등 더 풍부한 요청 메타데이터를 제공합니다. protobuf-ts의 unary 및 서버 스트리밍 캡처와 Connect-Web/protobuf-ts 기본값 스칼라 표시를 추가했고, 다크 모드와 상세 화면 구성, JSON 검색 성능, 유휴 상태 이후 연결 복구, 재전송 상태 및 대용량 스트림 기록의 메모리 관리도 함께 개선했습니다.
